Mermaid Flowchart Example

    flowchart TD

    A[Start: Read package.json] --> B[Load lockfile.json 4000+ lines]
    B --> C[Build Dependency Graph]
    C --> D[Detect Conflicts: version mismatches]

    D -->|Conflict Found| E[Trigger: npm ls --json]
    D -->|No Conflict| F[Proceed: npm ci clean install]

    E --> G[Suggest Minimal Fix]
    G -->|Upgrade Specific Package| H[Trigger: npm install <pkg>@latest]
    G -->|Downgrade Specific Package| I[Trigger: npm install <pkg>@<version>]
    G -->|Replace Package| J[Trigger: npm uninstall <old> && npm install <new>]

    H --> K[Rebuild Graph: npm ls]
    I --> K
    J --> K

    K --> L[Trigger: npm dedupe]
    L --> M{Conflicts Remaining?}
    M -->|Yes| G
    M -->|No| N[Trigger: npm shrinkwrap / lockfile update]

    N --> O[End: Stable Environment Ready]
